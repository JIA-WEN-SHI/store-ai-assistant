## 项目背景与职责

面向小型实体门店，设计经营看板、营销助手、客户管理、记账、库存与话术模块。现有前端主要使用预设内容和本地交互。

我的职责：需求探索、产品设计与前端原型。

## 当前范围

形成前端交互原型和面向商家的演示材料，未使用真实用户业务案例验证经营效果。

公共交互入口展示现有前端，以明确标记的模拟内容演示。

## 源码结构

`src/ · public/`

这是当前工作区源码的发布快照，未附带旧 Git 历史。真实密钥、数据库、浏览器会话、日志、客户原始金融材料和依赖缓存不在仓库内。

## 无后台演示

在前端地址后加 `?demo=1`，可直接进入示例经营看板。所有经营数据与 AI 回复均为界面演示。

## 本地运行

需要 Node.js 24。

```bash
npm ci
npm run dev
```

生产构建：`npm run build -- --base=./`。现有测试：`npm test`。经营数据与 AI 回复属于预设演示内容。
